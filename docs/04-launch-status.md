# Launch status

## Built

- Separate local Git project: HindiWithNeelam.
- Astro static pages, Tailwind styling, strict TypeScript, inline CSS, self-hosted fonts and astro:assets WebP images.
- USA and Australia hubs; six city guides; four learning pathways; four resource articles; teacher, approach, editorial, privacy and accessibility pages.
- Working city-aware time conversion, including daylight-saving gaps/repeated times and half-hour zones.
- Enquiry preparation with real WhatsApp/email handoff, adult/guardian acknowledgement, safe text rendering and no silent message sending.
- One-page Hindi practice PDF.
- Production/preview indexing controls and automatic sitemap.
- CI configuration and repeatable local validation/browser scripts.

## Not represented as completed

- GitHub push is complete: https://github.com/Aviicoder/HindiWithNeelam, branch `main`. The owner created the repository; the project was pushed through the existing Git connection. Repository visibility and GitHub Actions results have not been verified through the restricted API.
- No domain has been registered or availability verified.
- No Cloudflare project has been deployed. The supplied preview build is intentionally noindex. Set the verified SITE_URL and rebuild for public indexing.
- US population figures have not been independently verified; source year/methodology are absent. Australian city rankings remain provisional without a comparable dataset. Public pages do not repeat unsupported counts.
- Hindi-specific teaching qualifications, fees, lesson duration, timetable and learner ages await owner confirmation. They are not invented.
- Initial resource examples have not been represented as reviewed by Neelam. Have her review them before asserting teacher authorship or review.

These boundaries do not prevent local use or testing. They distinguish a working website from external publication and unconfirmed business information.
